3D Printing

The chassis itself is 3D-printed, not bought as hardware — but the printer and filament are the other line items in the ~$600 estimate.

Already own
Printer — Bambu X1C
256×256×256mm build volume — well above the guide's ≥180×180×180mm minimum, so the standard Set A/Set B plates should fit without needing the Small Build Plate Alternative STLs.
Filament — PETG Basic or PETG HF
~365g used across the full part set. Set A prints at 0.16mm layers (default strength); Set B prints at 0.12mm (higher strength) for the more highly-loaded parts.
